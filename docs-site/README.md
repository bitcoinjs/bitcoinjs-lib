# Documentation site development

Use Node.js 20 or later for the VitePress site. Run these commands from the repository root.

```sh
npm ci
npm run doc:dev -- --port 4173 --strictPort
```

Open [the local preview](http://127.0.0.1:4173/bitcoinjs-lib/). Run `npm run doc` to build the static site into `./docs`, the directory uploaded by GitHub Pages CI.

Both commands use TypeDoc to generate API pages and the sidebar from `ts_src/index.ts` before running VitePress.

## Roadmap

1. **Documentation preview.** Review the VitePress homepage, local search, and API reference generated by TypeDoc.
2. **Guides.** Start with one recurring user workflow. Reuse examples from the integration tests so the guide and tests can share the same code.
3. **Browser Playground.** Prototype a read-only transaction decoder using a CDN module pinned to the documented bitcoinjs-lib version. Run the decoder in the browser and include a sample transaction.
